# Documentation

Knowledge left behind by agents and humans working on this repository, organized by type.
Each folder's `README.md` is the index of its contents — keep it up to date whenever a
document is added, renamed, or removed.

| Folder | Contents | Index |
| --- | --- | --- |
| [adrs/](./adrs/README.md) | Architectural and design decision records | [adrs/README.md](./adrs/README.md) |
| [plans/](./plans/README.md) | Plans produced by agents, skills, or workflows | [plans/README.md](./plans/README.md) |
| [memories/](./memories/README.md) | Durable facts agents learned about this repository | [memories/README.md](./memories/README.md) |
| [learnings/](./learnings/README.md) | Lessons learned: failures, gotchas, corrections | [learnings/README.md](./learnings/README.md) |

This structure is defined by the `stella-agentic-workflow-docs` plugin from
[stella.agentic.workflow](https://github.com/rochar/stella.agentic.workflow).
